# 都市狂飙：自由之城

一款面向手机浏览器的原创 3D 开放世界驾驶原型。

## 当前版本

- Three.js 3D 场景与海滨城市街区
- 第三人称人物移动、跳跃、跟随镜头
- 可进入/离开红色跑车并进行驾驶
- 触屏虚拟摇杆、动作按钮、横屏布局
- 键盘 WASD、空格、E 键支持桌面试玩

## 本地/网页运行

这是纯静态网页项目。将仓库部署到支持静态站点的托管平台，入口文件为根目录 `index.html`。Three.js 从 jsDelivr CDN 加载，首次打开需要网络。

## 操作

- 左侧摇杆 / WASD：移动或驾驶
- 跳跃 / Space：跳跃
- 上车 / 下车 / E：靠近红色跑车互动
- 冲刺：步行加速
- 视角：旋转跟随视角

## 说明

这是独立原创原型，借鉴开放世界动作与驾驶游戏的玩法类型，不使用 GTA 的角色、地图、素材或代码。当前优先验证 iPhone 浏览器操作和核心循环，后续再扩展 NPC、交通、任务、警察系统与画面表现。
